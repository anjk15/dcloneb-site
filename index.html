Get started

You need macOS or Windows, uv (a free installer), and Claude: the desktop app or Claude Code.

  1. Install dcloneb
    uv tool install "dcloneb[mcp] @ https://anjk15.github.io/dcloneb-site/downloads/dcloneb-0.2.0-py3-none-any.whl"

Then connect it to the Claude you use:

Claude Desktop app

Best for most people. You approve with a click in your browser, and Claude can't skip it.

  1. Quit Claude Desktop first (Cmd+Q), then connect it 
    dcloneb mcp install --workspace ~/dcloneb-workspace
  2. Check it works
    dcloneb mcp test

Open Claude Desktop, start a new chat, and ask.

Claude Code (terminal or VS Code)

For developers. Everything happens in your terminal or editor.

  1. Connect it 
    dcloneb mcp install --client claude-code --workspace ~/dcloneb-workspace
  2. Check it works
    dcloneb mcp test --client claude-code

Start a new Claude Code session and ask.

Approval is a guardrail here: Claude Code can also run shell commands, so watch what it proposes.

Put your schema.sql in ~/dcloneb-workspace and ask: “Use the dcloneb tools to make 20 rows per table from schema.sql in my dcloneb workspace.” Your data lands in ~/dcloneb-workspace/<name>/csv/.

Good to know

Your data and privacy

Data is generated on your computer and files stay on your computer, inside your workspace folder; dcloneb will never overwrite a file. Nothing is generated until you click Approve on a page served only on 127.0.0.1 (it works once and expires in 10 minutes). Claude sees your schema, rules, and summaries, so those reach your model provider; generated values are shared only if you ask Claude to preview rows.

What's supported

Column types

SMALLINT INT BIGINT SMALLSERIAL SERIAL BIGSERIAL DECIMAL BOOLEAN VARCHAR TEXT CHAR DATE TIMESTAMP UUID

Business rules

RuleMeaning
rangethe value is >= / > min and <= / < max (whichever bounds are given), compared exactly
allowed_valuesthe value is one of `values` (decimals by value, text exact and case-sensitive)
formatthe value matches the format; only `email` (the documented strict ASCII syntax)
value_kinda generation guide for what the values are (product names, cities, ...); checked as non-empty text that fits

Not supported yet (refused with a clear reason)

  • FKs sharing child columns with another FK (`overlapping_foreign_keys`)
  • CHECK (`check_constraint`)
  • generated columns (`generated_column`)
  • partial or expression unique indexes, table properties (`unsupported_plan_diagnostic`)
  • triggers, functions, views, row-level security (the CSVs satisfy declared constraints only)

Limits

Up to 100,000 rows per table and 1,000,000 in total by default.

Use it without Claude 
dcloneb make schema.sql --rules rules.json --rows 100
